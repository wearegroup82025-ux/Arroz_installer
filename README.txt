ARROZSISTEMA SIMPLE INSTALLER WEBSITE

1. Put your installer file inside:
   installer/

2. Rename your installer exactly to:
   ArrozSistema.exe

3. Upload the whole folder to your web hosting.

4. Open index.html in your website.

That's it. Users only need to click "Download Installer".

If your installer has another filename, either rename it to ArrozSistema.exe
or change this line in index.html:
href="installer/ArrozSistema.exe"

No database, PHP, admin panel, or other setup is required.
